HOW IT WORKS

ONE PORTAL.
ONE DATABASE.

The website is the front end. Google Sheets is the group's database. Google Apps Script connects them. Add a new trip or location in the Sheet and the website can display it automatically.

IMPORTANT // Do not put private passwords, financial information or sensitive personal information into this public portal. For a large group, add authentication/admin controls later.
